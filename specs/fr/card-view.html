Description

Le composant CardView est une vue « fiche produit » compacte qui met en avant un élément unique avec ses statistiques, ses sections et ses actions. Elle convient à la présentation d'un produit, d'un profil utilisateur, du détail d'un événement, ou de toute entité unique demandant un affichage détaillé.

La carte comprend :

  • Titre et intro
  • Description
  • Badge (facultatif)
  • Image principale (facultative)
  • Statistiques (paires clé-valeur)
  • Sections (titre + texte)
  • Éléments de mise en page parmi les sections — paragraphe, espaceur, séparateur, les trois mêmes que le formulaire
  • Boutons d'action
  • Métadonnées personnalisées

Le client dessine la carte comme une surface unique en quatre zones — en-tête, statistiques, sections, actions — séparées par un filet pleine largeur ; une zone vide n'est pas dessinée. Les statistiques sont une liste libellé / valeur, jamais cliquable. Actions : la primary en bouton plein, les deux premières secondary en boutons contour, toute autre action (secondary au-delà, puis link) en ligne de liste avec chevron, dans l'ordre donné.

Exemples de code JavaScript

Carte simple

import { YeriaApp } from '@numerum-tech/yeriasdk';

const yeriaApp = new YeriaApp({ appId: 'my-app' });

const card = yeriaApp
    .createCardView('product-card', 'Super Gadget')
    .setIntro('Boost your day')
    .setDescription('A compact companion to organize your tasks and automate your daily routines.')
    .addStat('Price', '49 €')
    .addSection('Key Points', 'Voice assistant, 48h battery life, multi-device sync.')
    .addAction('Buy Now', 'POST', { confirmMessage: 'Confirm your purchase?' });

const response = yeriaApp.serve(card);

const card = yeriaApp
    .createCardView('product', 'Product Name')
    .setIntro('Product Category')

Carte avec éléments de mise en page

Les trois éléments de mise en page du formulaire prennent place parmi les sections, dans l'ordre des appels. Une carte dont le seul corps est un paragraphe est valide ; un espaceur ou un séparateur seul n'est pas un contenu.

const card = yeriaApp
    .createCardView('laptop', 'MacBook Pro 16"')
    .addSection('Fonctionnalités', 'Processeur avancé • Écran haute résolution • Longue autonomie')
    .addSeparator('Détails techniques')
    .addSection('Spécifications', 'Puce M3 Pro • 18 Go RAM • 512 Go SSD')
    .addParagraph('Les caractéristiques peuvent varier selon la configuration choisie.', { size: 'sm', italic: true })
    .addSpacer('lg')
    .addSection('Garantie', 'Garantie limitée 1 an • 90 jours de support gratuit')
    .addAction('Acheter maintenant', 'POST', { variant: 'primary' });

Réinitialisation des éléments d'une carte

const card = yeriaApp
    .createCardView('dynamic-card', 'Dynamic Card')
    .setDescription('Card with dynamic content')
    .addStat('Stat 1', 'Value 1')
    .addStat('Stat 2', 'Value 2')
    .addSection('Section 1', 'Body 1')
    .addAction('Action 1', 'POST');

// Clear stats
card.clearStats();

// Clear sections
card.clearSections();

// Clear actions
card.clearActions();

// Clear image
card.clearImage();

Carte dans un parcours en plusieurs étapes

const card = yeriaApp
    .createCardView('step-summary', 'Step Summary')
    .setProcess('onboarding', {
        processName: 'User Onboarding',
        currentStep: 2,
        totalSteps: 3
    })
    .setDescription('Review your information before proceeding')
    .addStat('Completed', 'Step 1')
    .addStat('Current', 'Step 2')
    .addStat('Remaining', 'Step 3')
    .addAction('Continue', 'POST');

Exemple de carte complexe

const card = yeriaApp
    .createCardView('product-detail', 'Premium Headphones')
    .setBadge('Best Seller')
    .setIntro('Wireless Audio')
    .setDescription('High-quality wireless headphones with noise cancellation and 30-hour battery life.')
    .setImage('https://example.com/headphones.jpg', 'Premium Headphones')
    .addStat('Price', '$299')
    .addStat('Rating', '4.8/5')
    .addStat('Reviews', '1,234')
    .addStat('In Stock', 'Yes')
    .addSection('Features', 'Noise cancellation, 30h battery, wireless charging, premium materials.')
    .addSection('Specifications', 'Driver: 40mm, Frequency: 20Hz-20kHz, Weight: 250g.')
    .addSection('Warranty', '2-year manufacturer warranty included.')
    .addAction('Add to Cart', 'POST', { 
        confirmMessage: 'Add to cart?',
        variant: 'primary'
    })
    .addAction('Buy Now', 'POST', { variant: 'primary' })
    .addAction('Compare', 'GET', { href: '/compare', variant: 'secondary' })
    .addAction('Share', 'POST', { variant: 'link' });
